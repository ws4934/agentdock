# 启动恢复、任务中心与滚动友好交互

## 范围

统一 macOS 普通启动、显式启动/重启和更新后的 Core/Tunnel 就绪检查；新增 Core 离线时也可读取的有界启动时间线；优化管理面板与常驻菜单栏任务入口；工作结果卡片支持宿主协商的 PiP/全屏和用户触发的续接。Recall 不在范围内。

## 决定

- 系统注册 enabled 不是进程或健康证明。统一协调器分别观察注册、进程与健康；可恢复失败至多重新注册一次，权限/配置/非预期健康响应不可盲重试。
- 用户停止意图持久化。普通打开窗口不能反转用户停止；首次配置只有显式启用才运行。配置事务中的临时停止不覆盖长期意图。
- 同一个服务只允许一个生命周期操作；重入返回 busy，不并发注销/注册。阻塞 ServiceManagement/launchctl 工作离开主线程。
- 启动时间线仅保存枚举阶段、次数与时间，不保存环境变量、URL、原始错误、命令或日志。Core 未启动不影响读取此时间线。
- 菜单栏/管理面板的任务中心是稳定入口。任务与 Job 回执仍由原存储负责；界面仅查询，不运行任务，不把复制续接提示当作已继续执行。
- 聊天卡片不是全局唯一悬浮窗。优先按宿主能力提供 PiP/全屏，拒绝或不支持时保留 inline 并提示从任务中心重新打开。绝不访问父页面 DOM、强制滚动或用 CSS 越过 iframe。
- 卡片内只读刷新更新当前实例；用户点击续接时发送只含严格验证任务 ID 的固定提示，要求先读取任务/回执，不重放已完成操作。请求宿主成功不代表模型已开始/完成。
- “已调用工具”行由 ChatGPT 控制，AgentDock 不承诺合并或隐藏。减少无恢复价值的轮询/展示与重复调用，不删除证据或隐藏错误。
- 不自动安装或重启当前服务。测试用注入驱动、隔离浏览器与临时状态目录；真实系统首次授权/冷启动属于安装后验收。

## 使用与故障边界

管理窗口顶部的“任务中心”和“诊断”入口及底部操作区固定，切换概览/连接设置或后台刷新不会改变用户调整的窗口尺寸。任务中心支持状态筛选、文本查找和完整任务编号读取；复制续接提示不会启动任务。关联回执中的源码指纹是执行时保存的历史记录，继续前仍需核对当前源码。

启动意图与最近 64 条枚举事件存放在 Desktop 实际运行目录下 `service-lifecycle.json`（macOS 默认 `~/Library/Application Support/AgentDock/`）。损坏或不可写时报告 `state_invalid`，不把未知停止意图当作运行授权；不会自动删除或重建用户状态。更新恢复也优先使用保存意图，而不是系统注册的瞬时状态。授权不足需由用户在系统设置中批准。

原生 API 客户端只允许 loopback 固定 GET 路由，拒绝重定向、超大响应和非本机主机；认证只放在请求头中。诊断导出仅包含枚举、版本、计数和时间，不读取原始日志或运行环境。公网检查为显式操作，成功不证明 MCP 认证、消息送达或 ChatGPT 渲染。

## 回归方式

生命周期覆盖 enabled 无进程、注册传播延迟、配置错误、需授权、不可恢复 HTTP 响应、有限修复、取消、重入和停止意图。任务覆盖部分列表、精确选择、无副作用续接；UI 覆盖模式协商拒绝/降级、滚动和 teardown、失效响应与重复点击。所有长验证通过 detached tmux 保留日志和退出码。
