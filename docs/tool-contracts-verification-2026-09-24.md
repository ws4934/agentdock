## 修复与验证

| 项目 | 实现和保护 |
| --- | --- |
| F1 认证头跨源转发 | 默认不跟随 HTTP 重定向；注入层再次核对 scheme/host/port。两个本机测试服务使用虚构认证值验证，没有访问真实凭据 |
| F2 隐藏元数据暴露 | 上游结果级 _meta 在 SDK 转换和外层投影分别防御，不进入模型数据或本地 UI 元数据，不修改原对象 |
| F3 反向行号 panic | 执行前范围校验和切片边界防御；意外处理器 panic 产生非重试、结果未确认的错误 |
| F4 长行续读丢内容 | 完整 revision + 行内字节位置游标；ASCII/中文/emoji/换行、多预算拼接还原和跨文件/过期拒绝测试 |
| F5 Session 回包丢失无法重取 | 同步、异步、终态和取消回执可重读；独立 stdout/stderr 字节游标；超期明确错误，二进制片段有 base64 保真 |
| F6 取消不能中断锁等待 | context-aware 锁、队列纳入超时、不占全局锁等待单个服务；关闭服务取消生命周期 |
| 分组 | 11个能力组，核心组保留；启动允许列表同步约束发现和调用；工具目录、MCP 描述符、API namespace 导出共享来源 |
| 输出契约 | 50个工具的成功 Schema 都拒绝空对象；生产 Runtime 也校验实际成功结果；关键动作参数在执行前验证 |
| 响应交付 | summary/json 明确模式；整体默认16 MiB预算；超限完整结果通过私有一小时资源引用交付，不重跑或假造成功 |
| Job 历史 | 独立分页游标、终态摘要索引、选中条目真实重读；归档移至分片墓碑，原 request_id 永不重放 |

实际动态 MCP tools/call 的网络失败不再提示自动重试；保留初始化/发现阶段的独立错误分类。分组不是文件访问沙箱，本地桌面授权、认证和既有能力开关仍然生效。

## 初次失败及处理

保留各轮原始失败日志：旧的消费式会话测试与新重读契约冲突后，测试改为独立字节游标；目录工具触发 Go 初始化循环后改为单次 init 构造；新运行时输出校验发现旧 ACP 概览 Schema 与 profile 列表不符后修正本地适配；map 遍历导致契约顺序不稳定后改成固定顺序；实际工具调用的非重试语义与初始化错误分类分别验证。真实浏览器首轮因未设置显式 Chrome 路径而拒绝执行，补充本机路径后真实重跑通过，没有把未执行记为通过。

没有关闭数据校验、放宽内存阈值或隐藏实际失败来获得最终通过。
